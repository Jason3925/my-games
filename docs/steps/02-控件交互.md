# 步骤 2 — 控件交互（Demo 优先）

> 返回：[步骤索引](./README.md)

---

## 目标

在 **Demo 页**把机身控件交互做扎实：方向键 3D Tilt + 阴影、A/B 与 Option 按下反馈、键盘映射。正式页可暂时只挂接视觉或仍保持静止——**本步不以主流程选游戏为目标。**

---

## 前置条件

- [ ] **步骤 1 已由你确认验收通过**
- [ ] 舞台图层与坐标可用（占位图亦可）

---

## 本步做什么

1. **D-Pad**
   - 四向热区（上/下/左/右；可设中心死区）
   - 3D Hover/Press Tilt：按方向倾斜，松手回弹
   - `dpad-shadow` 随倾斜偏移，增强体积感
   - 向外部抛出方向事件（供 Demo log；尚未驱动菜单）
2. **A / B**
   - 共用 action 贴图；按下下沉 + 阴影变化
   - 抛出 `a` / `b` 事件
3. **Select / Start**
   - 共用 option 贴图；同样按下反馈
   - 抛出 `select` / `start` 事件
4. **键盘映射**（与 [步骤文案.md](../步骤文案.md) 一致）：↑↓←→、Enter/Z/Space、Esc/X
5. **Demo 页**完整区块：
   - D-Pad Tilt 说明 + 事件 log
   - A/B、Option 说明 + log
   - （可选）简易操作说明文案
6. 组件放在 `src/components/`，Demo 与后续正式页共用，禁止 Demo 独有一份拷贝实现

---

## 本步明确不做

- 不实现 boot / menu 列表 / 封面切换
- 不引入完整状态机（`boot → menu → …`）
- 不做 zoom、蒙版、loading 流程
- 不创建游戏 iframe，不读游戏包
- 不要求正式页已经能「选出游戏并开始」
- 不做音效（除非你临时要求；默认不做）
- 不做部署
