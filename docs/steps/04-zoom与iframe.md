# 步骤 4 — Zoom、蒙版与 iframe（占位游戏）

> 返回：[步骤索引](./README.md)

---

## 目标

接上完整游玩环：**选游戏 → 放大并变暗外围 → 屏幕内 loading → iframe 加载占位页 → 游玩/查看 → B/Esc 返回全景并卸载 iframe**。  
本步用 **本地占位 HTML** 模拟游戏，不强制真 Godot。

---

## 前置条件

- [ ] **步骤 3 已由你确认验收通过**
- [ ] Menu 的 `onRequestStart` 可改为进入本步流程
- [ ] 至少 1 个占位入口，如 `public/games/placeholder/index.html`

---

## 本步做什么

1. 扩展状态：`zooming` / `loading` / `playing` / `zoom-out`（可合并 zoom+loading，但行为要齐）
2. **Zoom-in**：以屏幕为焦点放大/平移到舒适区
3. **外围变暗**：蒙版或等价手段；screen 保持突出
4. **Loading UI**：文案 + 进度条；尽量结合 iframe `load`（假进度可封顶 90%）
5. **iframe**：加载 `games.json` 的 `entry`（占位页）；进入 playing 时 `focus`
6. **返回**：B / Esc（及可选 postMessage）→ 卸载 iframe → zoom-out → menu（保留选中项）
7. 失败态：加载失败文案 + A 重试 / B 返回（见步骤文案）
8. Demo 页增加「Screen Focus Preview」：可不走全流程，一键预览蒙版+突出

---

## 本步明确不做

- **不接入** 真实 Godot WASM 导出（除非占位恰好是简单 HTML）
- 不做生产环境部署与自定义域名
- 不做移动端精细适配（可做不破版的最低限度；完整粗调放步骤 5）
- 不做插卡带、成就、多语言系统
- 不在返回后残留多个 iframe/WASM 实例
