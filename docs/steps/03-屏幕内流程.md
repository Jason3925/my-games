# 步骤 3 — 屏幕内流程（Boot + Menu）

> 返回：[步骤索引](./README.md)

---

## 目标

在 **全景机身、不缩放** 的前提下，打通屏幕内：`boot` → `menu`；用方向键切换游戏，右侧显示 mini 封面；按 A/Start 仅进入「已选定」的占位反馈（**真正的放大与 iframe 留到步骤 4**）。

文案以 [步骤文案.md](../步骤文案.md) 的 Boot / Menu 为准。

---

## 前置条件

- [ ] **步骤 2 已由你确认验收通过**
- [ ] `games.json` 至少 2 条占位游戏（可用假封面），便于测切换
- [ ] screen 内容区坐标已在步骤 1 标定

---

## 本步做什么

1. 引入 NES.css（仅作用于 screen 内容层容器）
2. 配置像素字体（至少保证中文或英文方案可读；按文案语言选择）
3. 实现状态：`boot`、`menu`（可先用简单状态变量；不要做 zooming/playing）
4. **Boot**
   - 进度条 + 启动文案
   - 自动结束进入 menu；可选 A/Start 跳过
5. **Menu**
   - 列表 + 当前项高亮
   - 右侧 mini 封面随选中项变化
   - 底栏提示文案
6. 将 D-Pad ↑↓、键盘 ↑↓ 接到列表选择
7. A / Start：在 menu 下触发 `onRequestStart(game)` —— 本步可用 **屏幕内短暂提示**（如 `READY: <title>` 或 log）代替真进入游戏
8. 正式页跑通上述流程；Demo 可保留控件实验室，并可选加「NES 样例」区块

---

## 本步明确不做

- **不做** zoom-in / zoom-out
- **不做** 外围变暗蒙版（留给步骤 4）
- **不做** iframe 加载游戏（包括不创建游戏 iframe）
- **不做** loading 进度对接真实资源
- **不做** playing 状态与返回卸载逻辑
- 不部署、不接真 Godot 包（占位封面与假 entry 字段可以有，但不要加载）

## 验收清单

### A. 代理自验

- [ ] 打开正式页先见 Boot，再自动进 Menu（或可跳过）
- [ ] 列表至少 2 项可切换；高亮正确
- [ ] 封面随选中项变化（无封面时有占位）
- [ ] D-Pad ↑↓ 与键盘均可选游戏
- [ ] A/Start 有明确占位反馈（非静默失败）
- [ ] 机身仍为全景，**没有**放大到屏幕焦点

- [ ] NES.css 样式大致限制在屏幕区内

- [ ] Boot / Menu 文案与观感可接受
- [ ] 选择与封面切换正确
