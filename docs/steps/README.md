## 验收门禁（强制）

每个步骤的完成流程固定为：

```
代理实施
   ↓
代理按「验收清单」自验，并在对话中汇报结果（通过 / 未通过 + 证据）
   ↓
你按同一清单手动验收
   ↓
你明确回复「步骤 N 验收通过」
   ↓
才允许开始步骤 N+1
```

| 约定 | 说明 |
|------|------|
| 未确认不往下做 | 即使代理自验全过，没有你的确认也不得开下一步 |
| 失败则停在本步 | 任一项未过 → 只修本步，不提前做后续范围 |
| 范围以文档为准 | 「本步做什么 / 不做」写死了边界；想加需求先改文档再实施 |
| 清单打勾 | 验收时按清单逐项；可写「通过」或指出具体失败项 |
