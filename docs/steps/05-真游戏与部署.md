# 步骤 5 — 真游戏接入与部署

> 返回：[步骤索引](./README.md)

---

## 目标

接入至少 **1 个** Godot HTML5 导出，替换占位游玩；完成静态站点部署，使朋友可以通过 URL 打开并完整走通：开机 → 选游戏 → 加载 → 游玩 → 返回。

---

## 前置条件

- [ ] **步骤 4 已由你确认验收通过**
- [ ] 你提供至少一个 Godot Web 导出目录（或导出步骤由你本地完成后再交给仓库）
- [ ] 选定托管平台（Cloudflare Pages / GitHub Pages / Vercel 等）

---

## 本步做什么

1. 将 Godot 导出放入 `public/games/<id>/`，更新 `games.json` 与封面
2. 验证 iframe 内可玩（键盘/焦点）；按需约定 `postMessage` 退出
3. 处理部署相关配置：WASM MIME、路径、若启用线程则 COOP/COEP（或改为单线程导出）
4. 移动端粗调：热区可点、首屏比例不严重裁切、返回仍可用
5. 正式构建与部署；输出可分享 URL
6. 更新根 README：本地开发 + 已部署地址 + 如何新增一款游戏（简短）

---

## 本步明确不做

- 不扩展为多用户平台 / 账号 / 排行榜（非首期目标）
- 不重做步骤 0–4 已验收的交互，除非部署或真游戏暴露了 blocker 级 bug
- 不强制做插卡带动画、商店式详情页
- 不承诺支持 IE 等老旧浏览器
