## 0. 全局约定

### 0.1 输入映射

| 物理控件 | 键盘 | 语义 |
|----------|------|------|
| 方向键 ↑ / ↓ | ArrowUp / ArrowDown | 列表上一条 / 下一条 |
| 方向键 ← / → | ArrowLeft / ArrowRight | 预留（首期可无效果或轻微 tilt 反馈） |
| A（右侧偏上红键） | Enter / Z / Space | 确认 |
| B（右侧偏下红键） | Esc / X | 取消 / 返回 |
| Start | Enter（可选同 A） | 确认开始 |
| Select | — | 预留 |

### 0.2 屏幕内容层原则

- 所有文案、列表、进度条只出现在 **screen 内容区**内。  
- 使用 NES.css 组件风格；中文像素字体。  
- 机身按钮提供「掌机操作感」；屏幕内也可保留极简提示（如首屏 `↑↓ SELECT  A START`）。

### 0.3 动效时长（建议）

| 动效 | 时长 |
|------|------|
| Boot 启动序列 | 1.5s–2.5s（可点击 A/Start 跳过） |
| 列表切换 | 即时或 ≤150ms |
| 按钮按下视觉 | 80–120ms |
| D-Pad tilt 回弹 | 150–250ms |
| Zoom-in | 600–900ms |
| Zoom-out | 500–700ms |
| Loading 最短展示 | ≥400ms（避免闪一下） |

## 1. 阶段：Boot（开机）

### 目的
模拟掌机上电，建立「这是一台机器」的第一印象。

### 画面
- 全景 Gameboy（body + screen + 各按钮就位）。  
- 屏幕内：暗绿底 → 出现标题与进度条。

### 文案（屏幕内）

**方案 A（偏系统感）**

```
MY-GAMES OS
v0.1

BOOTING...
[=======---] 70%
```

**方案 B（偏欢迎）**

```
WELCOME
PLAYER

LOADING MENU...
[NES 进度条]
```

首期推荐方案 A；进度可用假进度 0→100，结束切 `menu`。

### 操作
- 默认自动结束。  
- 可选：按 A / Start → 跳过，直接 `menu`。

### 系统
- 预加载 `games.json`、封面图。  
- 不加载具体游戏包体。

### 转场
`boot` 完成 → `menu`（屏幕内容切换，机身不缩放）。

---

## 2. 阶段：Menu（游戏列表）

### 目的
选择要玩的游戏；建立「用十字键逛菜单」的习惯。

### 画面
- 仍为全景机身。  
- 屏幕布局建议：

```
┌─────────────────────────┐
│ SELECT GAME             │
│                         │
│ ▸ Game Title One        │  ┌─────┐
│   Game Title Two        │  │mini │
│   Game Title Three      │  │cover│
│                         │  └─────┘
│ ↑↓ MOVE    A START      │
└─────────────────────────┘
```

- 当前项：NES 风格高亮 / 前置 `▸` 或反色。  
- 右侧：当前游戏 `cover`；无封面则纯色块 + 标题首字。

### 文案

| 位置 | 文案 |
|------|------|
| 顶栏 | `SELECT GAME` |
| 底栏提示 | `↑↓ MOVE    A START` |
| 空列表 | `NO GAMES FOUND` |
| 加载清单失败 | `MENU ERROR` + `PRESS B TO RETRY` |

### 操作

| 输入 | 行为 |
|------|------|
| ↑ / ↓ | 切换选中项；右侧封面跟随；必要时列表滚动 |
| A / Start | 锁定选中项 → 进入 `zooming` + `loading` |
| B | 无上级则可轻反馈（闪一下或无操作） |
| 点击屏幕列表项 | 选中；再点一次或点 A 开始（可选，首期可只做机身键） |

### 系统
- 仅高亮与封面切换，不发起游戏加载。  
- 确认开始后才创建 iframe / 拉取游戏资源。

---

## 3. 阶段：Zooming + Loading（放大与加载）

### 目的
仪式感：从「桌上的掌机」过渡到「可贴脸玩的屏幕」；同时完成游戏资源加载。

### 画面
1. **Zoom-in**：以屏幕内容区为视觉重心放大/平移。  
2. **外围变暗**：body 与按钮区域被蒙版压暗或不突出；screen 保持清晰层级。  
3. **屏幕内**：加载文案 + 进度条（可覆盖在仍显示的菜单残影上，或先清成加载页）。

### 文案

```
LOADING
<游戏标题>

[========--] 80%

PLEASE WAIT
```

失败时：

```
LOAD FAILED
<游戏标题>

A RETRY    B BACK
```

### 操作
- Zoom / Loading 期间：**忽略**方向与开始（或仅允许 B 取消加载并 zoom-out 回 menu——首期可不做取消，防状态复杂）。  
- 失败：A 重试；B 回 menu（并 zoom-out）。

### 系统
1. 开始 zoom 动画。  
2. 创建隐藏或可见的 iframe，`src = game.entry`。  
3. 进度：假进度封顶约 90%，iframe `load`（及可选 `postMessage ready`）后到 100%。  
4. 满足「动画结束 + 加载完成 + 最短展示时间」→ `playing`。  
5. `iframe.focus()`。

### 转场
成功 → `playing`。失败 → 停留加载错误态，或 B → `zoom-out` → `menu`。

---

## 4. 阶段：Playing（游玩）

### 目的
玩家专注游戏；外壳弱化但返回路径清晰。

### 画面
- 屏幕焦点态保持；iframe 填满 **绿屏可绘制区**（保持比例，余下可用黑边）。  
- 外围持续变暗。  
- 可选：首次进入时屏幕外或角落短暂提示 `B / ESC TO QUIT`（2s 后淡出）。

### 文案
- 游玩中屏幕内文案由游戏自己负责。  
- 外壳提示（可选，一次性）：`B / ESC QUIT`

### 操作

| 输入 | 行为 |
|------|------|
| 游戏内操作 | 交给 iframe（需保证焦点） |
| B / Esc | 请求退出 → `zoom-out` |
| 游戏内 `postMessage` exit | 同退出 |

### 系统
- 退出时：暂停/静音（若可）→ 移除 iframe → 进入 `zoom-out`。  
- 不要在后台堆积多个 WASM 实例。

---

## 5. 阶段：Zoom-out（返回全景）

### 目的
平滑回到「可再选游戏」的柜机状态。

### 画面
- 蒙版退去，机身恢复全景比例与位置。  
- 屏幕回到菜单 UI（记住上次选中项）。

### 文案
- 动画过程屏幕可短暂空白或显示：

```
RETURNING...
```

- 结束后直接是 Menu 文案，无需长停留。

### 操作
- 锁定输入至动画结束。

### 转场
→ `menu`

## 6. 按钮视觉反馈文案（无字，仅行为说明）

### 6.1 方向键（Tilt）

| 分区 | 倾斜方向（示意） | 阴影 |
|------|------------------|------|
| 上 | 顶部压下 / rotateX 正 | 阴影略上移或缩小上缘 |
| 下 | 底部压下 / rotateX 负 | 阴影略下移 |
| 左 | 左侧压下 / rotateY | 阴影偏左 |
| 右 | 右侧压下 / rotateY | 阴影偏右 |
| 松手 | 回弹至中性 | 阴影回初始 |

同时可向逻辑层抛出 `dpad:up` 等事件（按下触发一次，或按住重复——列表建议 **按下触发 + 按住延迟重复**）。

### 6.2 A / B、Select / Start

| 状态 | 按钮贴图 | 阴影 |
|------|----------|------|
| 默认 | 原位 | 正常偏移 |
| 按下 | 向「键帽中心」下沉 1–2px（或轻微 scale） | 偏移减小 / 透明度降低 |
| 松开 | 回弹 | 恢复 |

A/B 共用 `btn-action` 资源；Option 共用 `btn-option`；靠布局位置区分。

## 7. Demo 页面步骤文案

Demo 页是给开发者（你）看的实验室，语气可以直白。

### 7.1 页头

```
MY-GAMES / COMPONENT LAB
测试机身控件与屏幕 UI，不进入完整游戏流程。
```

### 7.2 区块标题与说明

**D-Pad · 3D Tilt**

```
点击或按住十字键四个方向，观察倾斜与阴影。
输出：下方 log 显示 up / down / left / right。
```

**Action Buttons · A / B**

```
按下查看下沉与阴影变化。
A = confirm 反馈音（可选）  B = cancel 反馈
```

**Option Buttons · Select / Start**

```
与 A/B 相同的按下逻辑，贴图为 option 套件。
```

**Screen Focus Preview**

```
[预览聚焦] 模拟开始游戏后的蒙版变暗与屏幕突出。
[恢复全景] 回到默认合成。
```

```
在显示屏内容区预览：进度条 / 列表 / 对话框。
```

## 8. 主流程逐步脚本（验收用）

按下列顺序走通一遍即算首期体验达标：

1. **打开网站** → 见全景机身 + Boot 文案与进度条。  
2. **Boot 结束** → 自动出现 `SELECT GAME` 列表与封面。  
3. **按 ↓** → 选中项下移，封面切换；方向键有 tilt。  
4. **按 A** → A 键下沉；开始放大；外围变暗；出现 `LOADING`。  
5. **加载完成** → 进入游戏画面（首期可用占位 HTML 代替真 Godot）。  
6. **按 B / Esc** → 退出；iframe 卸载；缩回全景；回到列表。  
7. **再选另一款** → 可重复 3–6。  
8. **打开 Demo 页** → D-Pad / A-B / Option / 聚焦预览均可独立验收。

## 9. 文案用词统一表

| 场景 | 推荐用词 | 避免 |
|------|----------|------|
| 选游戏 | `SELECT GAME` | `选择您的游戏`（过长） |
| 移动 | `↑↓ MOVE` | `请使用方向键` |
| 开始 | `A START` | `点击开始按钮` |
| 加载 | `LOADING` / `PLEASE WAIT` | `拼命加载中` |
| 失败 | `LOAD FAILED` | `出错啦` |
| 返回 | `B BACK` / `B / ESC QUIT` | `点击返回首页` |

中英文混排时，**屏幕内优先短英文像素风**；若全中文，保持同等短句（如 `选择游戏` / `加载中` / `返回`）。
